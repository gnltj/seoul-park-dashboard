2. 테스트하는 방법
======================================================================


1) 프로젝트 폴더의 '실행.cmd'를 더블클릭합니다.
2) 열린 브라우저에서 다음 주소가 표시되는지 확인합니다.
   http://127.0.0.1:8765/demo/index.html
3) 종료하려면 실행된 명령 창에서 Ctrl+C를 누릅니다.

[명령어로 실행]
프로젝트 폴더에서 다음을 실행합니다.

   python run_demo.py

브라우저 통합 테스트까지 자동 실행하려면:

   python run_demo.py --test

또는 기존 데모 URL 끝에 '?test=1'을 붙여 접속합니다.
   http://127.0.0.1:8765/demo/index.html?test=1

포트 8765를 다른 프로그램이 사용 중이면:

   python run_demo.py --test --port 8766

주의: demo/index.html을 파일 탐색기에서 직접 더블클릭해 열지 마세요.
PyScript가 Python 소스를 읽을 수 있도록 위의 로컬 HTTP 서버를 사용합니다.

[처음 보이는 정상 상태]
- 샘플 목록: 가상 공원 6개
- 지도 마커: 5개 (샘플 중 1개는 좌표가 없음)
- 기본 정렬: 공원명 오름차순
- 화면의 공원 수: 6개 (좌표 없는 공원도 목록에 포함)

3. 직접 클릭하면서 확인할 기능
======================================================================

[ ] 지도 확대·축소·이동이 되는가?
[ ] 지도 마커를 누르면 공원명 등의 정보 팝업이 열리는가?
[ ] 목록에 공원명·지역·면적·개원일·관리부서 5개 열이 보이는가?
[ ] 목록의 공원명을 누르면 해당 마커 위치로 이동하고 팝업이 열리는가?
[ ] '지역'을 강남구로 바꾸면 결과가 2개, 마커가 1개가 되는가?
[ ] 최소 면적을 2000으로 설정하면 결과가 3개가 되는가?
[ ] 최대 면적을 1000으로 설정하면 결과가 2개가 되는가?
[ ] 목록 제목을 두 번 누르면 오름차순/내림차순이 바뀌는가?
[ ] 면적 입력을 모두 비우면 제한 없는 전체 결과로 돌아오는가?
[ ] 최소 면적을 9999999로 입력하면 결과 0개 안내가 나오는가?
[ ] 다시 입력을 지우면 공원 6개가 복구되는가?
[ ] 같은 필터를 여러 번 바꿔도 마커가 중복되지 않는가?

참고: 면적 입력은 값을 입력한 후 Enter를 누르거나 다른 입력칸을
클릭하면(change 이벤트) 반영됩니다.

자동 테스트는 다음과 같습니다.

   python -m unittest discover -s tests -v

PyScript·DOM·Leaflet 브라우저 통합 테스트 22/22 통과.
단위 테스트 23개는 별도 재검수에서도 모두 통과했습니다.

4. 구현한 Python 클래스와  클래스의 책임요약
======================================================================

MapDashboard.__init__(manager)
  - ParkManager "객체를 전달받아" 저장하고 정렬 기준 등 화면 상태를 관리

start()
  - 지도·구 선택 메뉴를 초기화하고 사용자 이벤트를 한 번 연결

refresh()
  - 현재 입력을 읽고 Manager에 필터·정렬 요청 후 지도·목록·개수 갱신

draw_markers(parks)
  - 기존 마커를 제거하고 공원 위치와 팝업을 다시 표시

draw_list(parks)
  - 5개 열의 표 머리글과 행을 만들고 클릭 가능한 공원명을 표시

on_filter_change()
  - 구/면적 입력이 변경되면 refresh() 호출

on_header_click()
  - 정렬할 열과 오름·내림차순 상태를 바꾸고 refresh() 호출

on_row_click()
  - 목록에서 누른 공원의 마커로 지도 이동 및 팝업 열기

설계에서 중요한 점:
* MapDashboard는 데이터 자체를 필터링하거나 정렬하지 않습니다.
* ParkManager.filter(), ParkManager.sort_by()에 데이터 처리를 위임합니다.
* Park.get_location(), Park.get_popup_html()을 통해 공원 정보를 얻습니다.
* 다른 객체를 생성자에서 전달받는 객체 합성/의존성 주입 구조입니다.
* 불필요한 상속 없이 각 클래스가 자기 책임만 수행하도록 했습니다.

호출 흐름:
사용자 이벤트 → MapDashboard.refresh() → ParkManager.filter()
→ ParkManager.sort_by() → MapDashboard.draw_markers()/draw_list()

5. 팀 코드와 통합할 때 맞춰야 할 계약
======================================================================

[HTML/CSS: 승진님 담당]
아래 ID 6개를 그대로 사용해 주세요.

  map         : 지도 영역(div), CSS 높이 지정 필수
  district    : 구 선택(select)
  min-area    : 최소 면적(input type="number")
  max-area    : 최대 면적(input type="number")
  park-list   : 공원 목록(table 또는 div)
  park-count  : 결과 개수를 넣을 요소(span 등)

주의: park-list는 tbody에 지정하지 마세요.
MapDashboard가 thead/tbody와 목록 행을 직접 생성합니다.
133개를 표시하면 표가 길어지므로 실제 CSS에서는 목록 영역에
세로 스크롤을 주는 편이 좋습니다.

Leaflet CSS/JS와 PyScript를 로드하고, Python은 DOM에 접근할 수 있도록
브라우저 메인 스레드에서 실행해야 합니다. PyScript 설정에는
map_dashboard.py 및 팀원의 Python 모듈 파일을 등록해야 합니다.

[ParkManager: 승진님 담당]
필요한 메서드 계약:

  get_districts()                       -> 지역 이름 목록
  filter(district, min_area, max_area)   -> 필터링된 Park 목록
  sort_by(parks, key, ascending)        -> 정렬된 Park 목록

정렬 키: name, district, area, open_date, department
기본 정렬: name / ascending=True

필터 인자 중 면적 입력칸이 빈 상태면 빈 문자열 ""을 그대로 넘깁니다.
숫자 0은 실제로 사용자가 입력한 0이므로 빈 값과 구분해야 합니다.
빈 면적을 0으로 바꿔 해석하지 말아 주세요.

[Park 및 DataLoader: 팀장님 / 서준님 담당]
필요한 Park 메서드 및 목록 속성:

  get_location()   -> [위도, 경도], 없으면 None 또는 [None, None]
  get_popup_html() -> 안전하게 구성된 HTML 문자열
  속성: name, district, area_text, area, open_date, department

MapDashboard는 원본 엑셀을 읽거나 면적 문자열을 숫자로 변환하지 않습니다.
위도·경도 누락 공원은 마커만 생략하고 목록·개수에는 포함합니다.
Park의 팝업 HTML은 데이터 텍스트를 HTML 이스케이프하여 제공해 주세요.

[팀 프로그램 시작 코드]
실제 DataLoader/ParkManager가 준비된 뒤 아래처럼 연결합니다.

  from map_dashboard import MapDashboard
  dashboard = MapDashboard(manager)  # 실제 Manager 객체
  dashboard.start()

dashboard 객체는 페이지가 살아 있는 동안 유지해야 합니다.
실제 데이터가 준비된 후 start()를 호출하세요.
demo/main.py와 demo/mocks.py를 실제 팀 코드로 복사해 사용하지 마세요.

6. 문제 발생 시 빠른 확인
======================================================================

지도가 안 보임:
  - 인터넷 연결, Leaflet 로딩, map 영역 CSS 높이 확인

Python 모듈을 찾지 못함:
  - PyScript 설정에서 map_dashboard.py 및 다른 모듈 파일 매핑 확인

필수 HTML ID 오류:
  - 5번의 ID 6개가 실제 HTML에 있는지, Python보다 먼저 만들어졌는지 확인

지도는 보이지만 공원 목록이 없음:
  - Manager.filter()/sort_by() 반환값, park-list 요소 타입 확인

목록은 보이지만 마커가 적음:
  - Park.get_location()의 반환이 [위도, 경도] 순서인지 확인
  - 좌표가 None인지, 누락 좌표를 보완했는지 확인

팝업에 HTML이 깨지거나 링크가 위험해 보임:
  - Park.get_popup_html()의 HTML 이스케이프 및 링크 검증 확인

면적 없는 공원이 사라짐:
  - 면적 입력이 비었을 때 Manager에 0이 아닌 ""이 전달되는지 확인
  - 실제 필터링 정책은 ParkManager 쪽에서 점검
