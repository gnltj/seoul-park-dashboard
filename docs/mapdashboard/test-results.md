# 4개 클래스 구조의 검증 결과

검증일: 2026-11-02 (Asia/Seoul). 아래 결과는 새 4개 클래스 코드로 다시 실행한 결과입니다. 구버전의 23개 단위 테스트를 그대로 통과했다고 표시하지 않습니다.

## 독립 자동 테스트

| 종류 | 실행 | 실패 | 오류 |
|---|---:|---:|---:|
| CPython 단위 테스트 | 33 | 0 | 0 |
| PyScript·DOM·Leaflet 브라우저 테스트 | 22 | 0 | 0 |

출력 원문은 unit-tests.txt와 browser-tests.txt입니다. 단위 테스트는 Dashboard의 객체 협력, 입력 검증, 팝업 생성/링크, 좌표, 정렬/선택 알림을 검증합니다. Dashboard는 js import 없이 CPython에서 가짜 화면 객체로 시험합니다.

브라우저 테스트는 실제 DOM 이벤트와 Leaflet을 사용합니다. 지도·5개 열·개수, 마커 위치/팝업, 행 반복 클릭, 구/최소/최대 면적 조건, 빈값과 0의 구분, 5개 열 정렬 전환, 누락값/누락 좌표, 결과 0개/복구, 반복 start/refresh, 연속 필터 변경, 정렬 후 행 연결, 텍스트 출력, div 컨테이너를 확인했습니다. 팝업은 get_popup_html() 없는 MockPark로 검증하며 전화번호·링크 및 누락값 빈칸을 확인합니다.

환경: Python 3.12.14, 내장 Chromium 브라우저, PyScript 2026.7.3, Pyodide 0.29.0, Leaflet 1.9.4, OpenStreetMap 타일. 데모는 run_demo.py --port 8768 --test --no-browser로 실행했습니다.

## 실제 팀원 코드의 임시 연결

Git 작업 폴더 밖의 임시 검증 폴더에 팀원의 파일을 읽기 전용 원본 그대로 복사하고 이번 네 클래스만 연결했습니다. 실제 main.py, Park, DataLoader, ParkManager, HTML, CSS, PyScript 설정, parks.csv를 수정하지 않았습니다. 이 임시 파일들은 브랜치에 포함하지 않습니다.

- main.py 기준: ce7e7db22754430d94b4fd62ed49b7f4207e2304
- Park 기준: 3309201aa9aea2e997556afadf7c25fefadcbc16
- DataLoader/CSV 기준: 5f07a9cbd47ecb54dff3cc18a657a0fbcc41f492
- Manager/화면/설정 기준: baf6242d43354eafb3857d280620b7dbc0c83af8

브라우저의 실제 목록 133개·마커 133개를 확인했습니다. 강남구 선택 결과 7개, 최소 면적 2000 결과 127개 및 제한 해제 후 133개 복구, 면적 정렬과 행 선택 후 실제 공원 팝업도 확인했습니다. 이는 해당 시점의 팀 코드와 화면 연결을 검증한 것이며 데이터 정제 정확성이나 최종 배포까지 보증하지 않습니다.

## 수정 및 미검증 범위

링크 테스트가 Leaflet 자체 닫기 링크까지 세던 부분을 팝업 내용 영역으로 한정했습니다. 실제 공원 설명이 길어 팝업 최대 높이를 300px로 정하고 내부 스크롤을 적용했습니다.

모든 브라우저/모바일 기기의 교차 검증, 원본 엑셀의 133개 값 정확성, 원본 좌표 보완의 정확성, GitHub Pages 최종 배포는 검증 범위에 포함하지 않습니다. 테스트 수는 구버전과 다를 수 있으며 결과는 위 두 출력 파일에서 확인합니다.
